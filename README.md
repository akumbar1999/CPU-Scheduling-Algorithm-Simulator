CPU Scheduling Algorithm Simulator

About the Project

The CPU Scheduling Algorithm Simulator is an Operating System mini project designed to demonstrate how different CPU scheduling algorithms work. It helps users understand process execution through simulation and Gantt chart visualization.

Features

- FCFS (First Come First Serve)
- SJF (Shortest Job First)
- SRTF (Shortest Remaining Time First)
- Priority Scheduling
- Round Robin Scheduling
- Gantt Chart Visualization
- Waiting Time Calculation
- Turnaround Time Calculation

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open "index.html" using Live Server.
4. Enter process details.
5. Select a scheduling algorithm.
6. Click the Simulate button.
